第二章：运动控制。核心是drive.c中的PID闭环系统。

Drive System · 驱动系统

PID 闭环驱动 — drive.c

核心机制

  • TIM1 中断：每 10ms 执行一次 PID 计算
  • 差速 PID：diff = 左编码器增量 - 右编码器增量
  • 直行：右轮 = 基准PWM + PID修正，左轮 = 右轮 - 75
  • 转向：固定 30% PWM 开环（不做 PID）
  • 停止：PWM 立即置 0，清除积分/误差
Kp=10 Ki=2 Kd=5 PWM=600 (30%) 自动模式+40

中断伪代码

// TIM1_IRQHandler · 每10ms delta_l = Encoder_L() - last_l; delta_r = Encoder_R() - last_r; diff = delta_l - delta_r; // >0 = 左轮快 corr = Kp*diff + Ki*integral + Kd*(diff-last_diff); clamp(corr, ±150); // 右轮=基准+修正，左轮=右轮-75 pwm_r = 600 + corr; pwm_l = pwm_r - 75; Motor_SetSpeed(pwm_l, pwm_r);

左轮恒比右轮少 75 PWM，补偿电机特性差异；自动模式下基准 PWM 从 600 提升至 640。

PID闭环7/12
drive.c是运动控制核心。TIM1每10ms触发中断，读取编码器增量计算左右轮速度差，PID修正后更新PWM。直行时左轮恒等于右轮减75（补偿电机差异），自动模式额外+40 PWM。转向时切换为开环固定PWM。PID参数：Kp=10, Ki=2, Kd=5，修正量限制±150。

弓形路径9/12
auto_mode.c实现弓形路径规划：直行碰障→后退300ms拉开距离→重新判定左右障碍→根据障碍情况选择U-turn方向→交替左右U-turn形成弓字清扫。U-turn=两次90°转向中间夹1秒直行。关键参数：TURN_90_MS=600ms, BACK_MS=300ms, STRAIGHT_MS=1000ms。碰障后先后退再判定，避免正前方墙体被误判为双侧障碍。
